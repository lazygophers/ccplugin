# 布局系统 · 响应式与场景自适应

布局是骨架。好的布局在不同屏幕、不同密度、不同信息量下都不塌。

## 间距尺度（Spacing Scale）

用固定阶数，禁任意数值。推荐 4px / 8px 基数：

```
--space-1: 4px    (微距：图标内、字间距)
--space-2: 8px    (紧凑内边距)
--space-3: 12px
--space-4: 16px   (标准内边距)
--space-6: 24px
--space-8: 32px   (区块间距)
--space-12: 48px
--space-16: 64px  (大留白)
--space-24: 96px  (段落级分隔)
```

所有 padding / margin / gap 取自这个阶。一致性 > 创意。

## 栅格（Grid）

```css
.container { max-width: 1200px; margin: 0 auto; padding: 0 16px; }
.grid { display: grid; gap: var(--space-4); }
```

常用列数：

| 场景 | 列数 | 列宽 |
|------|------|------|
| 内容阅读 | 1 / 12 | 文行长 60-80 字符 |
| 卡片墙 | auto-fit + minmax | 自适应填充 |
| 后台表格 | 12 栅格 | 自由跨列 |
| 移动 | 4 栅格 | 简化 |

`repeat(auto-fit, minmax(280px, 1fr))` 是响应式卡片墙的银弹——容器变宽自动加列，无需媒体查询。

## 响应式断点

采用移动优先（min-width 上叠）：

| 断点 | 宽度 | 布局变化 |
|------|------|---------|
| 默认 | <640px | 单列、堆叠、抽屉导航 |
| sm | ≥640px | 双列开始、横排按钮 |
| md | ≥768px | 侧栏出现、栅格展开 |
| lg | ≥1024px | 三列、固定侧栏、桌面密度 |
| xl | ≥1280px | 多列大屏、放宽 max-width |

每个断点改的是「布局结构」，不是「换个颜色」。结构变化：列数 / 导航形态 / 侧栏显隐 / 密度切换。

场景自适应（亮暗模式 / 密度切换 / 容器查询）单一真值源见 [scenes.md](scenes.md)，本文件不重复。

## 常见布局模式

| 模式 | 何时用 |
|------|--------|
| 圣杯（顶栏+侧栏+主+尾） | 后台、文档站 |
| F 型 | 文字密集页（扫描习惯） |
| Z 型 | 落地页（引导转化动线） |
| 卡片墙 | 等权内容集合（商品、文章） |
| 分屏 | 对比 / 双主区 |
| 居中聚焦 | 单任务（登录、表单、海报） |

## 布局自检清单

- [ ] 所有间距取自尺度阶，无魔法数
- [ ] 移动 → 桌面断点结构合理，无横向滚动
- [ ] 视觉焦点唯一明确
- [ ] 亮 / 暗模式均可读（如项目要求）
- [ ] 密度切换不破坏对齐（如项目要求）
