# 内容块清单

页面结构（规格第 4 节）：① 页头 ② 结论区 ③ 指标卡 ④ 正文面板网格 ⑤ 需要你做的事 ⑥ 出处 ⑦ 页脚 ⑧ 显性水印。必有：页头、结论区、正文面板（≥1）、出处、页脚。

| 块 | 对应内容 JSON | 用途 | 科研风 paper | 手绘风 sketch | 程序员风 terminal |
|---|---|---|---|---|---|
| 页头 | `title`、`subtitle`、`meta`、配置 `logo` / `author` | 标题与元信息（署名链接、生成时间、文档版本、产物类型、状态、上一版链接） | 顶部 6px 深红线海报横幅、大号衬线标题、斜体副标题，下接作者 / 发布日期 / 章节 / 引用四栏信息块 | 荧光笔高亮的大标题，右侧黄色便利贴写一句话结论 | `~/docs/<topic> v<N> $ cat <topic>.md` 提示行 + `# 标题`，等宽字体 |
| 结论区 | `summary` | 一句话结论 + 至多 3 条要点 | 期刊摘要框（灰底、上下细线），右栏编号要点 | 星形图标便利贴 + 三张微旋转彩色便利贴，带手绘对勾 | 「TL;DR」编辑器窗口卡片，`>` 前缀摘要与 `✓` 要点 |
| 指标卡 | `kpis` | 2–4 个关键数字 | 看板式细边框卡片，大号数字 + 单位 + 迷你柱 | 不显示 | 不显示 |
| 正文面板 | `heading` + 后续块 | 每个面板回答一个子问题 | 深红节号 + 衬线节标题、下划线；主栏 + 右侧 14em 旁注栏 | 彩色手绘编号圈 + 节标题 | `## 标题`，绿色前缀 |
| 段落 | `paragraph` | 正文 | 首行缩进衬线正文 | 浏览器默认字体正文 | 灰色等宽正文 |
| 列表 | `list` | 要点、风险与限制 | `(n)` 或 `•` 深红序号 | 手绘编号圈或手绘对勾，标题荧光笔 | `01` / `-` 绿色前缀 |
| 流程图 | `flow` | 步骤或数据流 | 细线方框 + 实心箭头，上下细线夹住，图注「图 n \| 标题」+ 旁注上标 | 马克笔手绘圆角框（浅色实填充、线条歪扭）+ 手绘箭头 + 编号圈 | 框线流程图，绿色描边、虚实交替，节点带 `[01]` 前缀，窗口卡片 `fig.n` |
| 有向图 | `graph` | 分叉与合并：git 分支、调用树、架构依赖 | 细线方框 + 实心箭头，跨行连线为平滑曲线，上下细线夹住，图注「图 n \| 标题」+ 旁注上标 | 马克笔手绘圆角框（按行着色：主线黄、分支蓝…）+ 手绘曲线箭头 | 框线有向图，绿色描边，窗口卡片 `fig.n`、`graph` 徽标 |
| 对比表 | `table` | 方案对比 | 三线表（顶底粗线、表头细线、无竖线），表注在上 | 手绘直角框包裹，表头荧光笔，虚线行分隔 | 编辑器窗口卡片 `table.n`，`compare` 徽标，细边框表格 |
| 术语表 / 配置表 | `kv` | 键值、配置项、术语 | 三线表，首列等宽 | 手绘框表格，首列等宽 | 窗口卡片 `config` 徽标，首列绿色等宽 |
| 统计图 | `chart` | 数值对比 | Tufte 极简区间图（点 + 连线、直接标值、无网格）、可选合计公式编号 (1)、旁注迷你柱 | xkcd 风格柱状图：手绘坐标轴、hachure 排线柱（各系列不同色）、数值标注，下方粉色说明便利贴 | 窗口卡片内柱状图（横向网格、圆角柱、底部图例、悬停提示），「chart / 数据」两个标签页切换图与数据表 |
| 代码块 | `code` | 关键实现 | 清单注在上，灰底代码区，旁注写文件名与语言 | 手绘框包裹，框内标注文件名 | 编辑器窗口卡片（标题为文件名、语言徽标），深色高亮 |
| 并排代码 | `codes` | 多文件 / 前后对照 | 多栏上下细线框，栏标题加粗 | 多个手绘框并排 | 多个窗口卡片并排 |
| 编号步骤 | `steps` | 操作步骤、需要你做的事、时间线 | `(n)` 深红序号 + 粗体标题 | 彩色便利贴卡片（交替微旋转）+ 编号圈 | `01` 绿色序号 + 粗体标题 + 灰色说明 |
| 叠放图 | `stack` | 优先级 / 层次 | 错位叠放方框，最上层深红描边，右侧覆盖方向箭头 | 同左，配色随风格 | 窗口卡片 `layers` 内叠放图 |
| 整页线框 | `wireframe` | 页面结构示意 | 线框 + ①–⑧ 图例 | 线框 + 荧光笔图例 | 窗口卡片 `layout` 内线框 + 图例 |
| 图片 | `image` | 截图、示意图 | 上下细线夹住居中图片，图注「图 n \| 标题」 | 手绘框包裹 | 窗口卡片 `image` 徽标 |
| 旁注 | 各块 `point` | 块要点 | 右侧边栏编号旁注，与图注上标同号 | 荧光笔要点行（感叹图标） | 不显示 |
| 需要你做的事 | 末节 `heading` + `steps` | 待确认、待决定、操作步骤 | 同编号步骤 | 同编号步骤 | 同编号步骤 |
| 与上一版的变更 | `changes`（v≥2） | 版本差异 | 正文前「Δ 与上一版的变更」节，列表样式同列表 | 同左，手绘样式 | 同左，终端样式 |
| 结论 | `conclusion` | 文末一句话 | 最后编号节「结论」 | 黄色便利贴「一句话：」 | `## 结论` |
| 出处 | `references` | 编号参考 | 「参考文献」编号列表 + 「引用本文」 | 页底 `[n]` 小字列表 | 分隔线下 `[n]` 小字列表 |
| 页脚 | CLI 填写 | 左：show-me v<版本> · github.com/lazygophers/ccplugin（锁定）；中：文档 v<N> · 生成时间；右：署名链接 | 三段细字，顶部分隔线 | 同左 | 同左，深色底 |
| 显性水印 | 配置 `watermark.visible` | 版权标识 | 全页 -30° 平铺黑字，透明度默认 0.06 | 同左 | 白字平铺 |

字体：不打包、不内联任何字体文件。科研风用 CSS 通用族 `serif`，程序员风全页与各风格代码处用 `monospace`，手绘风正文不指定字体（沿用浏览器默认），手绘感只来自线条、色块、荧光笔等图形元素。

其余按需块的对应：时间线用 `steps`（`title` 写日期）；附录用 `heading`（`level: 1` 分部标题）+ 任意块；风险与限制用 `list`。
