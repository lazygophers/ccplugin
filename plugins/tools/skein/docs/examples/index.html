设计理念

自然海滩色彩语言

取自近海清透蓝+金沙滩暖调，摒弃厚重深蓝，开阔松弛。无实景图片，依靠渐变+模糊光晕实现海岸氛围感。

层次克制原则

蓝色为主功能色，金色仅作高亮点缀，不抢夺任务信息焦点，长时间浏览视觉舒适。

海浪动效体系

缓动曲线模拟海浪起伏，卡片悬浮、状态切换带有弹性回弹，拒绝生硬线性过渡。

标准化色彩体系

完整包含品牌色、文字层级、边框背景、状态语义色，满足业务开发直接落地。

DAG 图

通用有向无环图 (DAG) 组件 — 4 种典型布局, 节点 4 态色 (默认/进行中/完成/失败), 边实线=强依赖 虚线=弱依赖。纯 SVG+CSS, 零依赖。

默认 (待执行) 进行中 (脉冲) 已完成 失败 强依赖 弱依赖 (可选) 流动 (active)

① 竖向树 DAG · Vertical Tree

自上而下分层依赖: 根任务 → 子任务 → 叶任务, 适合展示层级化拆分 (A→B,C / B→D / C→E,F)。

② 水平 DAG · Horizontal Pipeline

左→右流向, 典型 pipeline: 输入源 → 并行处理 (A/B) → 汇聚合并 → 输出, 适合展示数据处理 / CI 流程。

③ 菱形决策 DAG · Diamond

决策菱形: 开始 → 判断节点 → 是/否分支 → 汇合结束, 适合展示条件路由 / 审批流 (否分支常伴随失败态)。

④ 并行分支 DAG · Fan-out / Fan-in

单源 fan-out 到 N 个并行 worker (含失败/进行中态) 再 fan-in 汇聚, 适合展示并发任务调度 / MapReduce。
