## 职责范围

订单域负责订单生命周期管理, 包括:
- 订单创建 (从购物车结算)
- 订单支付 (对接支付域)
- 订单履约 (库存扣减/发货)
- 订单完成/取消

## 域边界

**上游依赖**: 用户域 (用户信息)、商品域 (价格/库存)、购物车域 (结算项)

**下游服务**: 支付域 (支付指令)、物流域 (发货请求)、通知域 (状态推送)

## 与其他域关系

| 关联域 | 交互方向 | 关键数据 |
|---|---|---|
| 用户域 | 读取 | userId, 收货地址 |
| 商品域 | 读取 | SKU 价格, 库存 |
| 支付域 | 调用 | 支付单号, 支付结果 |
| 物流域 | 调用 | 发货单, 物流轨迹 |

订单域本身不负责:
- 库存实际扣减 (由库存域负责)
- 支付渠道对接 (由支付域负责)
- 实物配送 (由物流域负责)
