## 前置检查

1. 用户登录态验证
2. 购物车商品有效性校验 (价格/库存/上架状态)
3. 收货地址完整性检查

## 库存锁定

调用库存域预扣库存:
- 成功: 进入订单落库
- 失败: 返回库存不足, 终止流程

## 订单落库

订单表落库字段:
- `order_id`: 订单号 (雪花 ID)
- `user_id`: 用户 ID
- `total_amount`: 总金额 (分)
- `status`: 订单状态 (待支付)
- `created_at`: 创建时间

## 支付引导

生成支付单并引导用户跳转支付域:
- 支付成功后通过回调更新订单状态
- 超时未支付自动取消 (15 分钟)
