# 根因复盘报告格式

同一问题定点修复多轮仍失败、继续盲修会扩大风险时，main 停止堆 subtask 做根因定位。5 维探针与取舍规则见 [flow-loop.md §9.3](flow-loop.md#93-根因复盘)，本文件只给报告模板。

```md
## 根因复盘

- 失败摘要：<最短可复现症状>
- 已尝试修复：<轮次 + 结果>
- 维度证据：
  - 需求理解偏差：<证据或排除理由>
  - 方案设计缺陷：<证据或排除理由>
  - 实现 bug：<证据或排除理由>
  - 环境或依赖：<证据或排除理由>
  - 测试本身错误：<证据或排除理由>
- root cause：<维度 + 一句话根因>
- 本次修：<定向修复建议>
- 同类防：<可复用契约；无则写无>
- 建议出口：<回 exec / 用户裁定回 planning / 新建 task>
```

每维都要给证据或排除理由，不能只查实现层。教训能写成可验证契约就走 `skein-spec sediment`，一次性问题跳过，不写流水账。
